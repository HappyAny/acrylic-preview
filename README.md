# 透色 · 亚克力色纸平面 / 3D 预览工作室

在浏览器中预览亚克力色纸的彩层、白墨、闪底、包边、背面底纹和局部镭射花纹。提供平面效果和可旋转的 3D 模型。画稿仅在浏览器内处理，无上传接口、统计脚本或外部 CDN。

```sh
git clone https://github.com/HappyAny/acrylic-preview.git
cd acrylic-preview
npm start
```

安装 Node.js 后即可启动；仓库包含预构建的 3D bundle。打开 http://127.0.0.1:4318/ 。服务器默认只监听本机，不会自动发布网站。

## 使用与运行

设置顺序为 01 画稿、02 白墨、03 尺寸、04 底板/闪底/包边、05 底纹和覆膜、06 光照。

默认打开“平面效果”，直接看清正面画稿、闪底、包边与装饰层；“3D 旋转”保留真实厚度、正反面和可控光照。两种模式共用参数、图层检查、A/B 对比和 PNG 导出。预览自动适应窗口，默认主体占可用画布的约 90%；工具栏与尺寸信息置于画布外，保持产品比例。桌面画布高度随浏览器高度变化；平面画布按显示比例分配像素，3D 在窗口缩放时保持观察角度和相对缩放。3D 默认正面，拖动旋转、滚轮缩放、右键平移；已移除地面及其阴影，不再出现硬边矩形或地平线。

白墨提供跟随彩层 Alpha、独立白墨图、满版、无白墨四种模式。独立蒙版支持透明度、白色为墨、黑色为墨三种解释；所有画稿使用同一个变换坐标。JPG 白背景不会自动去除。白墨预览最长边 1800 像素；成品 PNG 为 1800 × 1800，均为沟通预览而非生产分色文件。

JSON 方案 v6 保留底板类型和厚度、彩稿、白墨、自定义底纹、自定义膜纹、材质、预览模式、光照、相机位置；兼容 v1/v2/v3/v4/v5；v1–v5 的上传花纹保留按 Alpha / 原色的解释；v1–v4 的局部花纹按彩色印刷恢复；旧整面镭射膜转换为高透亮膜。单张图片不超过 20 MB / 4000 万像素，方案不超过 120 MB。分享方案文件也会分享其中的画稿。

开发命令依次为 npm ci --cache ./npm-cache、npm run build、npm test；启动命令为 npm start。已生成的 public/viewer3d.bundle.js 包含 Three.js 0.186.1 和所需附加模块；普通启动只需 Node.js。修改 scene3d.js / viewer3d.js 后必须重新构建。3D 模式需要 WebGL 2；平面模式使用 Canvas 2D，独立于 WebGL。浏览器回归测试使用独立的 Playwright / Chrome 会话。

## 按用户色卡补充的材质

包边共 17 款：流沙金色、银色、黑色、粉色、宝蓝、深蓝、浅蓝、酒红、大红、紫色、正绿、深绿、香槟金；素面镭射、亮金、亮银、亚金。另保留不包边与旧版基础包边。

闪底名称完整的 4 款：幻彩拉丝闪底、拉丝银葱、白葱闪底、银葱闪底。图底部两款名称截断，按可见外观暂记“淡紫细闪（暂定）”“幻彩镭射（暂定）”。保留旧版镭射、银闪、星星、珠光；旧方案的“透明底”自动转换为“无底板”。名称来自用户提供的两张图片；没有将推断名称写成已核实的店铺名称。

原照片未校色，也不是平铺纹理素材；本项目用程序生成微法线、粗糙度与薄膜厚度纹理。颜色、金属度、粗糙度、颗粒大小均为近似参数，不是实物测量结果。未复制用户原图到服务公开目录。

## 不透明纸板、内侧闪底、外侧底纹和顶面覆膜

- 底板：可选不透明纸板或无底板。纸板厚度默认 1 mm 是预览设定，可在 0.3–3 mm 内按实物调整；亚克力厚度独立设置。纸板靠亚克力的一面是闪底，向外的一面是底纹。无底板时同时移除纸板、闪底和底纹，保留彩层、白墨、亚克力和顶膜。
- 底纹：默认白纸洒金碎点，也可选择星芒、爱心、细点、菱晶、斜纹或上传自定义 PNG/JPG/WebP；可调颜色、强度、毫米间距。只出现在纸板外侧背面，纸板完全遮光，不会透出正面画稿或顶膜。透明 PNG 的留空处显示纸板原色。
- 覆膜：不覆膜、高透亮膜、细哑膜，可调效果强度。亮膜用柔和光带，哑膜用轻微散射和柔化。覆膜本身不镭射，只有花纹区域镭射。花纹镭射提供光柱 / 拉丝光栅、交叉光栅、碎钻切面、同心光纹、万向 / 八向光栅，具有方向和可见结构间距设置。
- 膜上花纹：与底纹独立的图案、颜色、强度和间距，或上传自定义图案。位于最上方，白墨不会遮住它；选择不覆膜时一并隐藏。
- 花纹透光可选半透明或不透明，适用于局部镭射和彩色印刷。不透明花纹的实体像素完全遮住画稿，上传 PNG 的透明留空与半透明边缘仍保留；镭射强度只调变色饱和程度，不会降低遮盖。未指定此字段时使用当前默认值“不透明”。
- 万向结构混合八个方向的变色光带，模拟多个观察方向都可见的局部镭射，仍是艺术近似，不保证与商家微结构一致。
- 背面底纹默认使用白纸洒金碎点，不规则稀疏分布；膜上花纹默认不透明，可手动切换半透明。
- 花纹画布：下载最长边 1800 px、与色纸同比例的 PNG；白色是图案，黑色留空，灰色表示部分覆盖。下载当前图案遮罩，无图案时生成纯黑空白画布，不含标注。编辑后在“膜上花纹”选择“上传图案”，默认按亮度 × Alpha 解读，黑底不会成为镭射整版；自定义彩色印刷用所选花纹颜色。旧版原色素材可切换按透明度。
- 局部花纹可选择镭射压纹或彩色印刷。镭射压纹按所选遮罩解释生成变色区域；彩色印刷在白色遮罩模式下采用所选颜色，按透明度模式下保留原色。自定义图案按整块色纸居中适配、保持比例；文件只在浏览器处理。
- 镭射预览使用连续结构域与角度相关的虹彩色带，转动相机或平面拖动时改变颜色和光带位置；3D 还响应光源方位、主光强度和环境强度。是基于照片外观的程序近似，不是精确衍射光谱或商家工艺复刻。结构间距是肉眼可见的分区尺寸，不是微观光栅周期。
- 两种模式均提供正面、背面与图层拆解。正面按“内侧闪底 → 白墨 → 彩墨 → 亚克力 → 覆膜 + 膜纹”合成，外侧底纹不参与正面着色。背面独立合成纸板和底纹；无底板的背面显示镜像彩稿，白墨位于彩稿之前。3D 纸板有实体厚度、朝内闪底面和朝外底纹面；拆解时整块纸板移动，保持两面位置关系。

## 3D 几何、白墨与光照

- 几何以米为单位，从输入 mm 转换。亚克力为实体 BoxGeometry；包边为具有中央孔洞的 ExtrudeGeometry 环，包覆正反面边缘与侧面，保留毫米比例。纸板实体位于亚克力后方，包边覆盖两者总厚度。
- 底材为 PBR 物理材质。拉丝使用各向异性与定向法线；流沙/银葱使用稳定的微法线颗粒；亮金/亮银使用低粗糙度金属；镭射用随观察角变化的薄膜虹彩近似。不是衍射光栅的光谱模拟。
- 闪底新增随视角响应的固定颗粒反光：葱粉颗粒按微面方向亮灭，拉丝高光移动，幻彩底随角度转色。平面模式跟随拖动，3D 跟随真实相机和灯光；没有时间驱动的随机闪烁。效果位于彩墨和白墨下方，满白墨完全遮住，彩墨继续过滤反射颜色；纸板背面的底纹无此效果。清透亚克力粗糙度设为 0，避免细小闪点被透射模糊。
- 彩层和白墨以独立纹理传入实际材质着色器。白墨覆盖同时增加白色底色、减少金属度、抑制虹彩和颗粒法线，并将各向异性变回各向同性。彩墨透射仍为 RGB 近似。
- 亚克力使用 transmission、IOR 1.49、实际厚度和距离衰减。该 IOR 是模型设定而非店铺材质测量。有纸板时采用玻璃透射；无底板时使用低透明度玻璃壳近似表面反光，避免实时透射缓冲不包含透明油墨而吞掉彩稿。透明面排序、背面和玻璃透射受实时渲染限制。
- 四个矩形柔光箱：主光、补光、轮廓光、背面柔光（随主光强度变化）。无实体地面。反射环境改为连续中性光棚，正前方有宽阔柔光，不使用硬边反射板或黑色相机孔。环境方向随光照参数变化，经 PMREM 预过滤；曝光/环境亮度调整不必重建环境贴图。低强度半球补光保留。
- sRGB 输出、Neutral 色调映射。降低玻璃粗糙度和表面泛白，减小粒子法线幅度并消除拉丝纹理的分块接缝。提供正面柔光、窗边日光、侧光看纹理三套预设，允许调整主光方位/高度、各灯强度、环境反射和曝光。A/B 共用当前相机和灯光，用于比较材质。

实现参考 Three.js 官方 [MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[RectAreaLight](https://threejs.org/docs/pages/RectAreaLight.html)、[PMREMGenerator](https://threejs.org/docs/pages/PMREMGenerator.html)。本项目不提供店铺 ICC、光谱油墨、底材 BRDF 或真实摄影棚的测量校准，屏幕效果不能替代实物打样。

## 代码与验收（2026-09-27）

- public/materials.js：色卡目录、材质参数及光照预设。
- public/model.js：参数清洗与蒙版/图像坐标。
- public/scene3d.js：实体模型、环形包边、程序纹理和白墨 PBR 着色器。

- public/lighting.js：连续中性环境照明。
- server.mjs：只公开白名单中的 9 个静态资源，不公开源码目录、测试、PID、日志和用户附件。
